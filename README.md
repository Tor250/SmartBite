# SmartBite

SmartBite помогает подобрать рецепт для конкретной кухни: из имеющихся продуктов или по пожеланиям, даже если часть продуктов нужно докупить. Пользователь может указать пищевые исключения, сложность приготовления, доступную технику и дополнительные условия. Войдя по почте, он получает историю рецептов, книгу, оценки и отзывы; рецепт можно открыть по ссылке для обмена.

Репозиторий содержит адаптивный веб-интерфейс, API и консольный сценарий. Логика приготовления отделена от HTTP-интерфейса, поэтому её можно вызывать из другого клиента. Проверка исключений использует ограниченный словарь: она не подтверждает безопасность продукта, не обнаруживает скрытые компоненты и следы перекрёстного загрязнения и не заменяет медицинскую консультацию.

## Состав проекта

- `frontend/` — веб-интерфейс на Next.js.
- `backend/` — API на FastAPI, сценарии приложения, адаптеры генерации, миграции и тесты.
- `architecture/` — архитектурные решения, C4, модель данных и контракт обмена рецептом.
- `.github/workflows/checks.yml` — сборка веб-интерфейса, проверки миграций и тесты на GitHub Actions.

## Быстрый запуск через Docker

```sh
cp .env.example .env
docker compose up --build
```

Веб-интерфейс доступен на <http://localhost:3000>, API — на <http://localhost:8000>. Без ключа внешнего генератора приложение запускает демонстрационный режим. Параметры генератора задаются в `.env`; файл `.env` не нужно добавлять в Git. Для работы интерфейса с другим доменом задайте адрес API в `NEXT_PUBLIC_API_URL` и добавьте адрес сайта в `SMARTBITE_CORS_ORIGINS`.

## Запуск без Docker

Backend, из каталога `backend/`:

```sh
python -m venv .venv
. .venv/bin/activate
pip install -r requirements-dev.txt
python -m alembic upgrade head
python -m uvicorn app.main:app --reload
```

Frontend, из каталога `frontend/`:

```sh
npm ci
npm run dev
```

Чтобы показать сценарий без веб-интерфейса, запустите из `backend/`:

```sh
python -m app.cli --mode from_products --products рис томат --exclusions молоко
```

## Проверки

Из корня проекта:

```sh
make test
```

Тесты охватывают разбор ответа генератора, проверку исключений, сценарии приложения, API, работу с базой данных и миграции. Для тестов задан минимальный порог покрытия 90%.

GitHub Actions запускает тесты и миграционные проверки с PostgreSQL, а также собирает frontend при каждом push и pull request.
