# ADR-004: Gemini Developer API для генерации рецепта

- Статус: принято для MVP
- Дата: 15.10.2026

## Контекст

SmartBite должен принимать рецепт от внешней языковой модели и разбирать название, ингредиенты, количества, шаги и времена. Для MVP важны единый JSON-формат, ограниченное ожидание ответа, простое подключение без отдельного сервера интеграции и возможность заменить поставщика позднее.

## Решение

Использовать Gemini Developer API через REST-метод `generateContent` и модель `gemini-3.5-flash-lite` по умолчанию. Google позиционирует Flash-Lite как экономичную модель для типовых задач и поддерживает для неё структурированный ответ по JSON Schema. REST вызывается стандартной библиотекой Python; сторонний SDK не требуется.

Ключ читается из `GEMINI_API_KEY`, название модели можно изменить переменной `SMARTBITE_GEMINI_MODEL`. Текст запроса отправляется в поле `contents`; JSON Schema и MIME-тип `application/json` передаются в `generationConfig`. Тайм-аут одного HTTP-вызова — 25 секунд, верхняя граница приложения — 30 секунд.

## Обоснование

- Пользователь предпочитает Gemini, а актуальная документация Google указывает Flash-Lite как недорогую модель для простых типовых задач.
- JSON Schema задаёт форму ответа с отдельными полями для ингредиентов, количеств и шагов.
- Прямой REST-вызов оставляет интеграцию небольшой и не привязывает прикладной сценарий к SDK.
- Цена по опубликованной таблице для Flash-Lite: $0.30 за 1 млн входных текстовых токенов и $2.50 за 1 млн выходных токенов. Например, условный вызов на 600 входных и 500 выходных токенов стоит около $0.00143. Реальная цена зависит от длины промпта и результата, тарифы и доступность бесплатного уровня могут меняться.

Актуальность модели и цены сверялась по [официальному каталогу моделей](https://ai.google.dev/gemini-api/docs/models) и [официальной таблице цен](https://ai.google.dev/gemini-api/docs/pricing) 15.10.2026.

## Передаваемые данные и ограничения

- В модель передаётся список продуктов и общая инструкция. Исключения профиля и медицинские сведения остаются в backend.
- Ключ находится только в переменной окружения и заголовке `x-goog-api-key`; он не записывается в журналы и не передаётся в браузер.
- Бесплатный уровень может использовать отправленные данные для улучшения продуктов Google. Для пользовательских данных до публикации нужно выбрать подходящий уровень обслуживания и проверить актуальные условия обработки.
- Структурированный вывод не гарантирует правильность рецепта. Backend самостоятельно разбирает результат и проверяет его по ограничениям, а safety gate блокирует найденное совпадение с пищевыми исключениями.
- Проверка исключений опирается на ограниченный словарь и не даёт медицинской гарантии; скрытые компоненты и перекрёстное загрязнение не определяются.
- При сетевой ошибке, пустом или некорректном ответе приложение сообщает об ошибке, не показывает рецепт и не переключается незаметно на демо.

## Последствия

MVP требует ключ Gemini для настоящей генерации. Без ключа сохраняется помеченный демонстрационный режим. Другой поставщик подключается заменой адаптера `RecipeJsonClient`; схема рецепта и проверки остаются общими. Повторные автоматические запросы не включены, чтобы не создавать непредсказуемые расходы.
