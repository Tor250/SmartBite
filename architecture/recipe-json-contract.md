# Контракт JSON для генератора рецептов

Документ описывает общий формат данных SmartBite и границу подключения генератора. Основной адаптер MVP использует Gemini Developer API; дополнительный адаптер позволяет при необходимости выбрать Qwen через Alibaba Cloud Model Studio. В обоих случаях остальная часть приложения остаётся независимой от поставщика.

## Запрос

Для текущего сценария SmartBite передаёт адаптеру JSON со списком продуктов:

```json
{
  "products": ["рис", "томат"]
}
```

Адаптер принимает системную инструкцию и JSON-ввод через `RecipeJsonClient.request_json(system_instruction, input_json)` и возвращает текст одного JSON-объекта. Gemini вызывается через REST `generateContent`, Qwen — через OpenAI-совместимый `chat/completions` endpoint; оба адаптера запрашивают структурированный JSON по общей схеме. В текущем MVP пищевые исключения остаются внутри backend: сервис проверяет по ним состав результата после генерации; исключения и медицинские сведения модели не отправляются.

## Ответ

```json
{
  "title": "Рис с томатами",
  "preparation_time_minutes": 20,
  "ingredients": [
    {"name": "рис", "quantity": "100 г"},
    {"name": "томат", "quantity": "1 шт."}
  ],
  "steps": [
    {"instruction": "Промойте рис.", "duration_minutes": 2},
    {"instruction": "Приготовьте рис с томатами.", "duration_minutes": 18}
  ]
}
```

Обязательные поля: `title`, `ingredients`, `steps`. В каждом ингредиенте обязательны `name` и `quantity`. В каждом шаге обязателен `instruction`. Общее время `preparation_time_minutes` и время конкретного шага `duration_minutes` могут быть `null` или отсутствовать. Если время указано, это целое число минут от 1 до 1440.

Backend ограничивает ответ 50 000 символами, список ингредиентов — 40 позициями, шаги — 12 позициями; текст названия — 200 символами, отдельного шага — 500 символами. Количество ингредиента проверяется по поддерживаемому формату (например, `100 г`, `1 шт.`, `по вкусу`).

## Обработка результата

1. По умолчанию адаптер отправляет список продуктов в Gemini Developer API. Qwen выбирается явно через `SMARTBITE_GENERATOR_ADAPTER=app.qwen_adapter:create_client`; его ключ читается из `DASHSCOPE_API_KEY`, модель — из `SMARTBITE_QWEN_MODEL` (по умолчанию `qwen3.8-flash`), endpoint — из `SMARTBITE_QWEN_BASE_URL` (по умолчанию международный endpoint Сингапура). Ключ и endpoint должны относиться к одному региону. Сетевой тайм-аут — 25 секунд; общий предел ожидания приложения — 30 секунд. Ответ ограничен 100 000 байт до разбора и 50 000 символов после получения JSON-текста.
2. Общий парсер проверяет структуру и поля, затем преобразует ответ в объекты рецепта. Некорректный JSON, отсутствующие обязательные данные и превышение ограничений приводят к отказу от результата.
3. Прикладной сценарий проверяет состав на пищевые исключения и убеждается, что генератор использовал только продукты из запроса. Он также ищет в названии и шагах известные словарю продукты, пропущенные в списке ингредиентов.
4. API возвращает рецепт пользователю только после успешного разбора и проверок. Ошибка генератора или проверки не приводит к показу непроверенного результата.

Проверка текста распознаёт только названия и словоформы, внесённые в ограниченный словарь. Она не выявляет все возможные скрытые компоненты. В ответе адаптера не должно быть Markdown-ограждений вокруг JSON. SmartBite не записывает текст запроса, список продуктов или полный ответ генератора в журналы. Если задан `GEMINI_API_KEY`, приложение по умолчанию использует Gemini; явно настроенный адаптер Qwen или другого поставщика имеет приоритет. Для нового поставщика переменная `SMARTBITE_GENERATOR_ADAPTER` задаёт фабрику `package.module:create_client`, возвращающую объект с методом `request_json(system_instruction, input_json)`. Если явно настроенный адаптер или ключ не работает, приложение не переключается незаметно на демонстрационный режим.

Для разработки ключ хранится в локальном `.env` (файл не добавлять в репозиторий) либо передаётся окружением. Для настоящих пользовательских данных следует отдельно проверить действующие условия обработки данных и выбрать платный уровень, если бесплатный уровень не подходит: Google указывает, что данные бесплатного уровня могут использоваться для улучшения своих продуктов. Текущие модели и цены приведены в [официальном каталоге моделей](https://ai.google.dev/gemini-api/docs/models) и [таблице цен Gemini API](https://ai.google.dev/gemini-api/docs/pricing).
